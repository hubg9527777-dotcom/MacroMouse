# MacroMouse

**MacroMouse** 是一款轻量的 macOS 菜单栏鼠标手势工具。按住右键绘制手势，即可向鼠标所指窗口执行复制、粘贴、撤销、随机文本、窗口控制或用户自定义键盘组合键。

本版本重点解决了右键手势在非前台窗口上执行时目标错误的问题：在右键按下的瞬间，应用会通过 macOS 辅助功能接口请求目标应用及窗口获得焦点；动作在同一次右键会话中执行，不需要先额外左键或右键点击切换窗口。

## 核心功能

| 功能 | 说明 |
|---|---|
| **窗口焦点同步** | 右键按下时定位鼠标下的可访问窗口，优先激活该窗口后再识别动作；权限或目标不可访问时自动降级，不阻断正常右键。 |
| **智能延后菜单** | 默认在按住右键时暂不显示菜单；识别为手势后消费右键事件，识别为普通右键点击后在抬键时补发原生右键菜单。可在设置中切回原生菜单行为。 |
| **八方向标准手势** | 上、下、左、右、左上、左下、右上、右下均可独立改绑。 |
| **右键双击触发器** | 与八方向一样可编辑，默认绑定“确认（↩）”，也可改为任意内置动作、组合键或不执行。 |
| **自定义图案** | 可录制任意右键轨迹并保存为图案。识别会忽略起点、尺寸和速度，保留方向与形状。 |
| **键盘组合键录制** | 在偏好设置内直接按下组合键录制，支持 ⌘、⌥、⌃、⇧ 与主键组合。 |
| **随机文本** | 可将任意手势绑定为从默认文本文件或专用文本文件中随机粘贴一条有效内容。读取在后台进行，不将文本内容写入日志。 |

## 推荐默认动作

用户可在“偏好设置 → 标准手势与右键双击”中随时修改以下默认映射，或一键恢复这些推荐值。

| 触发器 | 默认动作 |
|---|---|
| ↑ 上 | 复制（⌘C） |
| ↓ 下 | 粘贴（⌘V） |
| ← 左 | 撤销（⌘Z） |
| → 右 | 随机文本 |
| ↖ 左上 | 撤销（⌘Z） |
| ↙ 左下 | 最小化窗口（⌘M） |
| ↗ 右上 | 全屏切换；再次执行恢复窗口 |
| ↘ 右下 | 重做（⌘⇧Z） |
| 右键双击 | 确认（↩） |

> **提示：** 右键双击只是一个可配置触发器，而不是写死的功能。若不希望它执行确认操作，请把该项改为“**不执行动作**”或任意其他动作。

## 使用方法

1. 启动后，MacroMouse 会出现在菜单栏，不显示在 Dock 中。
2. 首次启动时，请在 **系统设置 → 隐私与安全性 → 辅助功能** 中授权 MacroMouse。该权限用于监听全局鼠标事件、切换目标窗口焦点和模拟键盘操作。
3. 点击菜单栏图标，打开“偏好设置”。在这里可以启用/停用手势、调整最小距离、选择随机文本文件和设置右键菜单行为。
4. 在“标准手势与右键双击”中选择任意触发器，点击“编辑动作”即可配置内置动作、随机文本或自定义键盘组合键。
5. 在“自定义图案”中点击“录制图案”，随后在任意位置按住右键画出轨迹并松开，填写名称和目标动作即可保存。

## 右键菜单行为

| 模式 | 手势期间 | 普通右键点击 | 适用场景 |
|---|---|---|---|
| **智能延后菜单（默认）** | 不显示菜单，识别成功后执行动作 | 抬键后补发原生右键菜单 | 希望手势过程干净、不显示菜单的日常使用 |
| **保持 macOS 原生菜单** | 系统会按下即显示菜单 | 完全保留系统原行为 | 少数与延后菜单不兼容的应用、远程桌面或特殊界面 |

当辅助功能权限缺失、目标应用不暴露可访问窗口，或系统暂时停用事件监听时，MacroMouse 会自动回退为原生右键，而不会吞掉用户操作。

## 随机文本文件格式

随机文本按行抽取；空行与以 `#` 开头的注释行不会参与抽取。例如：

```text
# 常用回复
收到，我会尽快处理。
谢谢，稍后回复你。
请把详细信息发给我。
```

可以在设置中点击“创建示例”生成文件。为防止误覆盖，已有文件会先备份为同目录下的 `.bak` 文件。

## 构建与安装

### 直接下载

可从 [Releases](https://github.com/secure-artifacts/MacroMouse/releases) 下载已打包版本。首次打开若显示“无法验证开发者”，请在 Finder 中右键点击 App，选择“打开”；该项目默认采用 ad-hoc 签名，尚未进行 Apple 公证。

### 本地构建

需要 Xcode 或 Swift 工具链。

```bash
git clone https://github.com/secure-artifacts/MacroMouse.git
cd MacroMouse

# Apple Silicon
./build.sh arm64

# Intel
./build.sh x86_64
```

构建完成后，`dist/` 目录会包含 `MacroMouse.app` 与对应 ZIP 包。也可以只编译不打包：

```bash
swift build -c release
```


## 安全与隐私设计

MacroMouse 仅在本机处理鼠标轨迹和文本文件，不上传用户输入、手势模板或文本内容。随机文本内容不会输出到控制台；配置保存在当前 macOS 用户的 `UserDefaults` 中。应用仅使用公开的 macOS 辅助功能与 Quartz 事件接口，并在调用失败时保持原生鼠标行为。
